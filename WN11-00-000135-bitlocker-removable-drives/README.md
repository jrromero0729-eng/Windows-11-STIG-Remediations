# WN11-00-000135 – BitLocker on Removable Data Drives

This folder contains remediation and verification scripts for DISA STIG WN11-00-000135 on Windows 11.

## Summary
Implements DISA STIG WN11-00-000135 by enforcing policy to require BitLocker encryption
for removable data drives before write access is granted.

## Included Files
- remediation.ps1
- verification.ps1
