# WN11-00-000170 – Disable AutoPlay

This folder contains remediation and verification scripts for DISA STIG WN11-00-000170 on Windows 11.

## Summary
Implements DISA STIG WN11-00-000170 by disabling AutoPlay to reduce the risk of removable media-based attacks.
