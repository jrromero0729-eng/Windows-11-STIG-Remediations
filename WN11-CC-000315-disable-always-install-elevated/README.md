# WN11-CC-000315 – Disable "Always install with elevated privileges"

This folder contains remediation and verification scripts for DISA STIG WN11-CC-000315 on Windows 11.

## Summary
Implements DISA STIG WN11-CC-000315 by disabling the Windows Installer policy
"Always install with elevated privileges" to prevent MSI packages from installing with elevated permissions.

## Included Files
- remediation.ps1
- verification.ps1
